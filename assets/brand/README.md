# Marca Clínica La Esperanza

Fuentes vectoriales de la identidad 2027 (CLEM 2027). De aquí salen los PNG
de `public/images/brand/` y los íconos de `src/app/`.

Paleta oficial:

| | Hex | Uso |
| --- | --- | --- |
| Azul marino | `#091f5b` | Color principal: titulares, botones, franjas oscuras |
| Azul medio | `#6f96d1` | Decorativo: no cumple contraste para texto sobre blanco |
| Azul claro | `#bad6eb` | Fondos suaves y acentos |
| Hueso | `#f0efeb` | Fondo de secciones |
| Taupe | `#d6c8af` | Acento cálido |

Tipografía del manual: Onmes (principal) y Nunito (apoyo). El sitio usa Nunito
porque Onmes es una tipografía comercial y no está licenciada en el proyecto.
